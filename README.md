## 🚀 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/officialdeepurajagopal/DeepuWebPage.git
   ```

2. Navigate to the directory:
   ```bash
   cd DeepuWebPage
   ```

3. Open `index.html` in your browser or use a local server:
   ```bash
   python -m http.server 8000
   # or
   npx serve
   ```

## 📝 Customization

### Colors
Edit CSS custom properties in `style.css`:
```css
:root {
    --primary-color: #2563eb;
    --primary-dark: #1e40af;
    /* ... more colors */
}
```

### Content
- Update HTML files with your own content
- Add new projects in `projects.html`
- Add new articles by creating new HTML files
